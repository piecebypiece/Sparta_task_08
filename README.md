# Sparta_task_08

### 구현 한 것

- 멀티웨이브구조
  - DataAsset 을 통해 각 웨이브별 시간과 정보 지정가능.
  - BP_GameInstance 에서 레벨과 레벨에서 사용할 웨이브 정보
- UI 리뉴얼
  - 체력을 바의 형태로 같이 표시
  - 현재 몇 번째 Wave인지 표시.
- 리팩토링
  - GameState 에는 게임의 **_상태_** 관련 변수와 함수만 남기고 적절한 곳으로 이동
  - GameMode 는 게임에 대한 로직만 남기고 이동

### 구현 하고 싶었는데 못한 것

- 웨이브 시작시 설정되는 Type 에 의해 함수를 실행하기.
  - WaveFunctionType 도 정의했고 웨이브 시작시 Type 별 함수를 호출할 준비도 해놓았으나 적절한 함수를 구현할 시간이 모자랐음.
- 캐릭터의 위치를 기록하여 지나간 길을 다시 못 지나가게 하기
  - 위치를 기록하고 위치마다 Capsule 충돌체를 만들고 이동 순서대로 캡슐을 연결하여 3D Snake 게임을 만들어보고 싶었으나
    시간 문제로 구현하지 못함.
- 웨이브 시간의 변화
  - 특정 아이템을 먹었을 때 웨이브의 남은시간이 느려지거나 빨라지거나 하는 효과
    - 시간을 TimerHandle 에서 Tick 으로 이동 시킴, 관련 아이템을 만들지 못함.
